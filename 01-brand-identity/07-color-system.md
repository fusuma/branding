# Brand Color System

## 1. Strategic Color Direction

The Flavio Fusuma color system is designed to communicate **trust, expertise, and craftsmanship** while maintaining a **warm, approachable personality**. The palette balances the stability and professionalism of a deep blue primary with the energy and memorability of an amber accent.

### Color Philosophy
- **Primary (Deep Blue)**: Conveys trust, depth, technical authority, and calm confidence
- **Accent (Amber)**: Adds warmth, energy, human touch, and visual distinction
- **Neutrals**: Provide structure, hierarchy, and breathing room
- **Semantics**: Ensure clarity in functional communication (success, warning, error, info)

## 7. Color Usage Guidelines

### Primary Application Rules

1. **Blue-800 (`#1E3A5F`)** is the brand's signature color. It appears in:
   - Logo primary colorway
   - Page headers and navigation
   - H1 and H2 headings
   - Footer background

2. **Blue-600 (`#2563EB`)** is the primary interactive color:
   - Buttons (primary)
   - Text links
   - Focus rings
   - Active navigation states

3. **Amber-500 (`#F59E0B`)** is used sparingly for emphasis:
   - Call-to-action highlights
   - Featured badges or labels
   - Decorative accents (underlines, borders)
   - Maximum 10–15% of any given layout

4. **Neutrals** provide the structural foundation:
   - Body text: `neutral-700` on light, `neutral-200` on dark
   - Secondary text: `neutral-500`
   - Backgrounds: `neutral-0`, `neutral-50`, `neutral-100`
   - Borders: `neutral-200`

### Color Ratio Guidelines

| Element | Recommended Ratio |
|---------|------------------|
| Primary blue | 20–30% of brand touchpoints |
| Accent amber | 5–15% (never dominant) |
| Neutrals | 55–70% (the canvas) |
| Semantic colors | As needed, contextually |

### Do's and Don'ts

**Do:**
- Use blue-800 for headers and key brand moments
- Use amber-500 to draw attention to CTAs and highlights
- Maintain generous whitespace (neutral-0) as the dominant "color"
- Test all color combinations for WCAG AA contrast compliance

**Don't:**
- Use amber as a background color for large areas
- Pair blue-800 text on blue-600 backgrounds (insufficient contrast)
- Use semantic colors for decorative purposes
- Modify brand colors with opacity for new "colors" — use the defined scale instead
- Use the extended palette for primary UI elements — reserve for data viz and illustration

## 8. Print Color Specifications

For print materials, use the following CMYK values:

| Color | CMYK | Pantone (Coated) | Notes |
|-------|------|-------------------|-------|
| Fusuma Blue | `68, 39, 0, 63` | 289 C | Primary brand color |
| Fusuma Amber | `0, 36, 96, 4` | 137 C | Spot color preferred for accuracy |
| Neutral Dark | `58, 47, 38, 76` | Black 7 C | Near-black for text |
| White | `0, 0, 0, 0` | — | Uncoated stock preferred |

### Print Notes
- Always request a press proof for brand blue — screen colors vary significantly from print
- Fusuma Amber may shift on uncoated stock; test and adjust CMYK accordingly
- For single-color printing, use Fusuma Blue (Pantone 289 C) as the primary ink
