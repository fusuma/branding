# Flavio Fusuma Brand Book — Overview

## About This Brand Book

This document serves as the master reference for the Flavio Fusuma brand identity. It is structured as a 20-page brand book that can be exported to PDF for presentation to clients, partners, and collaborators. Each page is self-contained while contributing to a progressive narrative: from strategic foundation to visual execution to practical application.

## Page-by-Page Outline

### Page 1 — Cover

Tagline "Craft at the intersection of code and design" in Inter Regular, Blue-200, below the name. Amber accent line (48px wide) centered below tagline. Version "Brand Identity v1.0.0 — April 2026" in Inter Regular, 10pt, Blue-400, bottom-center.

Opens with the brand purpose statement in display typography. Presents vision and mission as paired blocks. Full positioning statement formatted as a structured paragraph with bold key phrases. Target audience segments (Primary, Secondary, Tertiary) as cards with pain points, values, and how-we-serve. Competitive landscape table comparing Flavio Fusuma against freelance generalists and agency teams.

Three narrative pillars (The Craft, The Bridge, The Community) as full-width horizontal cards. Each card includes the pillar name, description, and three key messages. Visual treatment uses blue-50 background with blue-800 text and amber accent on the pillar number.

Tagline in display typography as the page hero. Elevator pitch in a styled block-quote. Messaging pillars as three cards with pillar name, headline, and supporting copy. Proof points listed below each pillar.

## How to Use This Brand Book

### For Brand Owners

This book is the single source of truth for all brand decisions. Before creating any new brand asset or approving any third-party usage, consult the relevant section. If a situation is not covered, extend the guidelines in a way that is consistent with the existing system and document the decision.

### For Designers

Use this book alongside the design tokens (`03-design-tokens/`) and Figma specifications (`06-figma-specs/`). The brand book provides the "why" behind design decisions; the tokens and Figma files provide the "how." When in doubt, the brand book takes precedence.

### For Engineers

The SCSS implementation (`04-styles/`) translates this brand book into production CSS. Cross-reference this book when you need to understand the intent behind a design decision. Token names and class names are derived directly from the naming conventions established here.

### For Partners and Collaborators

Start with this overview to understand the brand's structure and philosophy. Then consult the specific section relevant to your work. If you need brand assets, request the press kit (see `11-brand-governance.md`).

### For Export

This overview and the 11 brand identity documents (01 through 11) can be compiled into a 20-page PDF brand book using the page layout described above. The recommended export tool is Figma (using the page structure defined in `06-figma-specs/00-file-structure.md`) or InDesign for print-optimized output.
